# Internet das Coisas

Repositório destinado ao armazenamento das **atividades, exercícios e projetos desenvolvidos durante a disciplina de Internet das coisas**.

Aqui serão reunidos os materiais produzidos ao longo do curso, servindo como registro do desenvolvimento e como meio de entrega das atividades propostas em aula.

---

## Sobre a disciplina

A disciplina aborda conceitos e práticas relacionados ao desenvolvimento de aplicações para dispositivos, explorando ferramentas, linguagens, frameworks e boas práticas de desenvolvimento.

>  **Curso:** Desenvolvimento de Software Multiplataforma  
>  **Instituição:** FATEC Itaquera  
>  **Disciplina:** Internet das coisas

---

## Organização do repositório

Os conteúdos estão organizados de acordo com as atividades e projetos desenvolvidos durante as aulas.

```text
📦 FATEC-IoT
├── 📁 atividade-01/
├── 📁 atividade-02/
├── 📁 atividade-03/
├── 📁 projeto-01/
├── 📁 projeto-02/
├── 📄 .gitignore
└── 📄 README.md
```

A estrutura poderá ser alterada conforme o andamento da disciplina e a quantidade de projetos desenvolvidos.

---


## Tecnologias

As tecnologias utilizadas podem variar de acordo com cada atividade ou projeto.

Entre elas:

-  Desenvolvimento
-  Linguagens de programação abordadas na disciplina
-  Bibliotecas
-  Ferramentas de desenvolvimento

---

## Objetivo

Este repositório tem como objetivo:

- Organizar as atividades desenvolvidas durante a disciplina;
- Centralizar os projetos e exercícios realizados;
- Acompanhar minha evolução no desenvolvimento mobile;
- Facilitar a entrega das atividades;
- Servir como histórico dos projetos desenvolvidos ao longo do semestre.
